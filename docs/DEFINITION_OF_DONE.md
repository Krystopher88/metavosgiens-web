# DEFINITION OF DONE — METAVOSGIENS

Une fonctionnalité est terminée lorsqu'elle :
- respecte le PRD ;
- respecte DESIGN.md ;
- fonctionne sur mobile et desktop ;
- ne crée pas de régression ;
- est accessible au clavier si interactive ;
- respecte prefers-reduced-motion si animée ;
- possède les états vides/erreur/succès pertinents ;
- ne contient aucun contenu inventé ;
- passe le build de production.

Le site est considéré prêt lorsqu'il :
- respecte l'ordre des sections ;
- rend la promesse compréhensible rapidement ;
- donne accès au CTA principal ;
- permet de comprendre les quatre portes ;
- présente les trois cas sans chiffres inventés ;
- possède les cinq pages prévues ;
- fonctionne sans BDD ;
- dispose des bases SEO ;
- dispose d'un formulaire fonctionnel ;
- est responsive et accessible.
