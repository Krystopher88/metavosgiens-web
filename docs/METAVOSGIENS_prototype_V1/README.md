# Prototype MetaVosgiens V1

Prototype statique de la homepage MetaVosgiens by KRYST.

## Fichiers

- `index.html` : structure et contenus
- `styles.css` : direction visuelle responsive
- `script.js` : interactions des quatre portes et menu mobile

## Lancer

Ouvrir `index.html` dans un navigateur.

Les coordonnées de contact, mentions légales et éléments de preuve devront être remplacés par les données réelles avant mise en production.
